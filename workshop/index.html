1 · Install OpenClaw

macOS / Linux

Needs Node.js 22.22.3+, 24.15+, or 25.9+ and a model provider API key.

curl -fsSL https://openclaw.ai/install.sh | bash

Windows (PowerShell)

iwr -useb https://openclaw.ai/install.ps1 | iex

Then onboard

Walks you through provider, API key, and the Gateway.

openclaw onboard --install-daemon

2 · Ideaflow connector

Same MCP endpoint everywhere. Only the setup path differs by client.

The endpoint

Auth is OAuth — you sign in during setup. Nothing to install.

https://prod-api.ideaflow.app/v1/mcp

Cursor 1 click

Deep link — opens Cursor with the server prefilled.

Add to Cursor

VS Code 1 click

Deep link — opens VS Code with the server prefilled.

Add to VS Code

Claude Code 1 command

claude mcp add --transport http ideaflow https://prod-api.ideaflow.app/v1/mcp

Then run /mcp inside Claude Code to finish the OAuth sign-in.

Claude (web, desktop, mobile) copy + paste

No deep link exists for claude.ai connectors — this is the shortest real path.

https://prod-api.ideaflow.app/v1/mcp Open settings
  1. Copy the URL, then open connector settings
  2. Add custom connector → name it Ideaflow → paste the URL
  3. Connect, and sign in to Ideaflow in the popup
  4. Start a new chat — connectors attach at conversation start

ChatGPT plan-gated

Custom MCP connectors need Pro, Business, Enterprise, or Edu. Not available on Plus. On Business/Enterprise an admin enables developer mode first.

https://prod-api.ideaflow.app/v1/mcp Open settings
  1. Settings → Connectors → Advanced → Developer mode
  2. Create → paste the URL → Authentication: OAuth
  3. Sign in, then pick the connector from + in a chat

On Plus? Do the Claude path today — it works on every paid Claude tier.

3 · Birdclaw — your X archive, local

Request the archive first

X takes hours to days to prepare it. Start this now, set up the rest while you wait.

Request X archive

Install

brew install steipete/tap/birdclaw

Init, import, serve

birdclaw init && birdclaw archive find --json && birdclaw import archive --json && birdclaw serve

By @steipete, same author as OpenClaw · birdclaw.sh · repo

4 · Gramclaw — the Instagram sibling

Same idea for Instagram: local SQLite, visual search, moodboards, JSON-first CLI. Two versions — pick one.

Official recommended

By Art Jing. The upstream project.

npm install -g https://jacobcole.ai/downloads/gramclaw-1.1.0.tgz

github.com/artjing/gramclaw · download .tgz

Fork adds IG sign-in

My fork — adds direct Instagram sign-in on top of the official build.

npm install -g https://jacobcole.ai/downloads/gramclaw-fork-1.1.0.tgz

github.com/tmad4000/gramclaw · download .tgz

Try it with no Instagram login

gramclaw init --demo && gramclaw serve --open

Fictional sample content. For a real archive: gramclaw import archive ~/Downloads/instagram-export.zip --json
